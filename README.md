## ✨ Características Principales

Este proyecto no es una simple plantilla web, es una aplicación desarrollada con enfoque en el rendimiento, la accesibilidad y la experiencia de usuario:

* 💻 **Terminal Interactiva:** Un emulador de terminal integrado con comandos reales (`help`, `whoami`, `skills`) y algunos *Easter Eggs* ocultos (`sudo rm -rf /`).
* ⚡ **Rendimiento Extremo (Lighthouse):** Arquitectura optimizada para obtener calificaciones de élite en Google Lighthouse (Triple 100 en Accesibilidad, SEO y Best Practices, y +90 en Performance).
* 🌐 **PWA (Progressive Web App):** Funciona sin conexión (Offline) gracias a la implementación de un *Service Worker* personalizado y manifiesto web.
* 🌍 **i18n (Internacionalización):** Sistema de cambio de idioma nativo (Español/Inglés) sin recarga de página manejado mediante JSON.
* 📡 **Integración API REST:** Sección de proyectos sincronizada en tiempo real con la API de GitHub usando `Fetch`.
* 🎨 **Modo Oscuro/Claro:** Implementado con variables CSS (`:root`) y guardado en `localStorage`.
* 📱 **100% Responsivo:** Diseño fluido (`Flexbox` / `Grid`) adaptado a cualquier dispositivo.
* ✉️ **Formulario asíncrono:** Envío de correos mediante AJAX (usando Formspree) sin redirecciones molestas.

## 🛠️ Stack Tecnológico

La premisa de este proyecto es demostrar dominio de las bases de la web sin depender de librerías pesadas:

* **Estructura:** HTML5 Semántico.
* **Estilos:** CSS3 Puro (Variables, Flexbox, Grid, Animaciones).
* **Lógica:** Vanilla JavaScript (ES6+).
* **Optimizaciones:** Imágenes `.webp`, carga asíncrona de fuentes, minimización de *Main-Thread Work*.
* **Librerías externas mínimas:** FontAwesome (iconos asíncronos), Vanilla-Tilt.js (efecto 3D en tarjetas).

## ⚙️ Instalación y Uso Local

Al ser un proyecto estático puro, no requiere de Node.js ni procesos de build complejos:

1. Clona este repositorio:
   ```bash
   git clone [https://github.com/dsanchezisabel/my_web.git](https://github.com/dsanchezisabel/my_web.git)
   ```
2. Entra en el directorio:
   ```bash
   cd my_web
   ```
3. Abre el archivo `index.html` en tu navegador, o utiliza una extensión como **Live Server** en VS Code para poder visualizar las peticiones AJAX a los archivos `.json` locales correctamente.
